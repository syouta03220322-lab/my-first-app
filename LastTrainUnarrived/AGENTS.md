# LastTrainUnarrived — agent working agreement

Primary task specification: [3D_REBUILD_TASK.md](3D_REBUILD_TASK.md).

- Game is a Japanese first-person psychological horror train experience; realism and subtle tension are more important than loud jumpscares.
- Preserve all existing scenes, events, chapters, controls, save/load behavior, and original character identities.
- Prioritize detailed **seats, windows, hanging straps, luggage racks, ceiling, and advertisements**, then convincing differentiated faces and full-body 3D seated passengers.
- Prefer physically based GLB meshes and scene-specific LOD, and **profile performance** before/after. User reports about 20FPS; target playable 1080p/60FPS on suitable hardware, without promising it for all PCs.
- Inspect actual workspace before editing; local work in Codespaces may be uncommitted even if GitHub lists only README.md.
- Do not silently redistribute user-supplied third-party humanoid model assets.
- Implement, test, and document actual changes. Avoid superficial explanations or mock deliverables.
